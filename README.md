# Personal Website Template

This folder contains a static GitHub Pages template.

## Files

- `index.html` - page content and sections
- `styles.css` - responsive styling
- `script.js` - small dynamic behavior

## Customize

1. Replace placeholder text with your own biography, projects, and links.
2. Update `mailto:your.email@example.com` and social links in `index.html`.
3. Commit and push to your `Rawezh-cyber.github.io` repository.
4. GitHub Pages will serve the site at `https://rawezh-cyber.github.io/`.

You can preview locally by opening `index.html` in a browser.
